ABOUT THIS PROJECT

調査について

このサイトでは、日本・アメリカ・韓国・インド・フランス・ イギリスの6か国を対象に、映画のジャンルや人気度を比較します。

映画の製作国、ジャンル、評価、投票数、Popularity、 興行収入などのデータを使用しています。

映画データはTMDB APIから取得しています。 人気度やランキングは取得時点によって変化します。

DATA SOURCE: THE MOVIE DATABASE (TMDB)

This product uses the TMDB API but is not endorsed or certified by TMDB.
